# Surface Reconciliation Contract

Before release, exercise the exact candidate through the real `aella_cli` operator surface on a disposable or approved lab appliance.

- Confirm the documented prompt, `show`, `set`, `unset`, help, and exit surfaces match the implementation.
- Run read-only commands for version, hostname, network, and NTP state.
- Do not exercise a destructive mutation unless the release qualification explicitly authorizes the lab target and rollback path.
- Record candidate SHA, appliance identity, commands exercised, PASS/FAIL, and evidence.

Unit/static tests are supporting evidence only and cannot substitute for this operator-surface check.
